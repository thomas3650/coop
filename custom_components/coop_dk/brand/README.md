# Brand images

`icon.png` (256×256) and `icon@2x.png` (512×512) are a plain shopping-basket glyph drawn for this
project with Pillow, in `#41BDF5` on a transparent background. They carry no Coop logo or mark.

Home Assistant 2026.3 and later serves these local images for custom integrations, and HACS's brands
check accepts `brand/icon.png`.
